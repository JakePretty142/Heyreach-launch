# Warm × HeyReach launch page

Landing page for the HeyReach integration, live at heyreach.getwarmai.com.

- Next.js (App Router), no other dependencies.
- Light and dark mode (sun/moon toggle in the nav, remembers the visitor's choice).
- Design source: Figma "Warm AI — Website Redesign", page "06 · HeyReach launch".

## Run locally

    npm install
    npm run dev
